# fonts/

UI and cinematic fonts with clear open or commercial licences suitable for a paid game.

## Intended contents

- One primary UI sans and optional mono for terminal/readout flavour.
- Licence file and attribution text beside each family.

## Godot use

DynamicFont / FontFile resources. Do not rely on OS-installed fonts for shipping builds.

## render_type

font (treat as `ui` dependency in the manifest if a dedicated type is not used).

## Rule

No font without a redistributable licence on file.

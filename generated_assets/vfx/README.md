# vfx/

Lightweight gameplay and cinematic visual effects.

## Intended contents

- Kinetic Accelerator: muzzle flash, linear trail, sharp impact sparks.
- Breach Charge: arming pulse, radial blast flash, shockwave ring, debris burst.
- Material responses: metal sparks, glass shards, electrical arcs, energy overload, concrete dust.
- Temporal accents: restrained cyan distortion (not full-screen neon).
- Flipbooks and particle textures with documented frame timing.

## Godot use

Coding agent implements particle systems and triggers. This folder supplies textures, flipbooks and recipes only.

## render_type

`sprite` (flipbooks, glows) and particle textures. Occasional simple `mesh` for shockwave rings if useful.

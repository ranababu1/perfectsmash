# Privacy Policy — Temporal: First Jump

This policy describes version **1.0.0-rc1** of Temporal: First Jump as audited on **2026-11-11**.
Publisher contact: `<owner contact email>` (to be filled in by the publisher before publication).

## Summary

Temporal: First Jump is a fully offline, single-player game. It does not collect, transmit or share any personal information.

## Information we collect

None. The game does not collect personal data, does not read device identifiers, and does not access your location, camera, microphone or clipboard. It has no accounts, no advertising, no in-app purchases, no leaderboards and no analytics.

## Information stored on your device

The game stores one small file in the app's private storage on your device. It contains:

- mission results and scores,
- Research Data (the in-game currency) and weapon upgrade levels,
- your settings (sound, music, vibration),
- which story sequences you have already seen.

This file is used only to keep your progress and settings. It is never transmitted off the device. It is removed when you uninstall the app (Android) or clear the app's data.

## Network access

The game contains no networking code. It makes no HTTP requests, opens no sockets and does not connect to any server. The game does not request the Android INTERNET permission, so it cannot go online.

## Third parties

The game uses no third-party SDKs, plugins, advertising or analytics services. It is built with the Godot engine only. No data is shared with any third party.

## Permissions

The only Android permission the game requests is VIBRATE, used for haptic feedback. You can turn vibration off in Settings.

## Children

Because the game collects no personal information from anyone, it collects none from children.

## Changes to this policy

This statement is accurate for version 1.0.0-rc1 as audited on 2026-11-11. If the app changes (for example by adding online features, advertising, analytics or new permissions), this policy must be re-checked and updated before that version is released.
